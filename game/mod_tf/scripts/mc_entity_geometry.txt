// TF2MC: Minecraft mob geometry (box-UV cubes, like Minecraft's own entity models).
// Textures come from YOUR Minecraft jar: tools/mc_assets.py packs every texture named here into
// materials/mc/entities.vtf. Mobs not listed here are drawn as simple coloured shapes.
//
//   model <entity id> [more ids...]          ids without "minecraft:"
//   height <blocks>                          adult hitbox height; the model is scaled to the real
//                                            hitbox (babies, slime sizes, giants)
//   tex <slot> <path[|fallback...]> <w> <h>  texture (relative to textures/) and its UV layout size
//   skin <entity id> <slot> <path[|...]>     another texture for one of the ids sharing this model
//   part <name> <parent|-> <px> <py> <pz> [rot <x> <y> <z>] [anim <a>] [tex <slot>]
//   box <u> <v> <x> <y> <z> <w> <h> <d> [inflate <f>] [mirror]
//   end
//
// Model space is Minecraft's: pixels, y DOWN, the ground at y = 24, the mob faces -z, +x is its
// left. Rotations are radians (applied Z, Y, X like ModelPart). Animations: head, leg_l, leg_r,
// arm_l, arm_r, zombie_arm_l, zombie_arm_r, wing_l, wing_r, tail, tentacle, bob.
